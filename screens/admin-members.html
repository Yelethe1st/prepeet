What each role can do

This is the whole permission model. There are no hidden capabilities behind any of these roles.

Permission matrix: what Recruiter, Hiring manager, Tenant admin and Read-only can each do
Capability Recruiter Hiring manager Tenant admin Read-only
Yes Scoped roles only No

Text summary: Recruiters and hiring managers work only within the roles they are scoped to. Only tenant admins can change rubrics, members, integrations or retention. Read-only members can read evaluations but cannot record a decision, export data or send an invitation. No tenant role can see another tenant's data, and no tenant role can see platform operations.

Everyone who opens a candidate's transcript is recorded in the audit log, whatever their role. Access is logged, not just granted.
