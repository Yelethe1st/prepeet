# Component inventory

Every reusable component in the Prepeet prototype, its class names, where it is defined and where it
is used. Live examples of all of them are in [`design-system.html`](../design-system.html).

The rule the prototype follows: **a component is defined once in `assets/css/components.css` (or
`layout.css` for structural shells) and reused by class**. Pages do not re-implement components. The
application chrome goes further — sidebar, topbar and mobile navigation are generated by
`assets/js/shell.js` from one config, so there is exactly one implementation of each.

## 9. States

| Component | Classes | Standard copy pattern |
| --- | --- | --- |
| Empty state | `.state`, `.state-icon`, `.state-compact` | What is missing · why · the one action that fixes it |
| Error state | `.state.danger` | What failed · what is safe · retry · a reference id |
| Permission denied | `.state.danger` / `.state-page` | What was requested · the required role vs the current role · what you *can* reach · request access |
| Insufficient evidence | `.band-insufficient`, hatched `.comp-bar` | What was captured · why it cannot be scored · what would fix it |
| Loading | `.skeleton*`, `.spinner`, `.progress.indeterminate` | Skeletons mirror the shape of the real content |
| Disabled | `:disabled`, `[aria-disabled="true"]` | Always paired with an explanation of the precondition |
| Full-page state | `.state-page` | 403 / 404 / 500 |

## 10. Shared behaviour API — `assets/js/ui.js`

| Attribute / call | Effect |
| --- | --- |
| `[data-tabs]`, `[data-tabs-param]` | Full tab keyboard contract, URL-addressable |
| `.accordion-trigger[aria-controls]`, `[data-accordion-single]` | Accordion with exclusive-open option |
| `[data-dialog-open]`, `[data-drawer-open]`, `[data-dialog-close]` | Modal open/close with focus management |
| `[data-menu="id"]` | Dropdown with click-outside and `Esc` |
| `[data-tooltip]` | Positioned tooltip on hover and focus |
| `[data-toast]`, `Prepeet.toast()` | Toast notifications |
| `[data-toggle-target]`, `[data-toggle-class]`, `[data-pressable]` | Generic show/hide and pressed toggles |
| `[data-segmented]` | Segmented control state, optional URL sync |
| `[data-copy]` | Copy to clipboard + confirmation toast |
| `[data-loading-sim]` | Simulated async action with an optional destination |
| `.ring[data-score]` | Score ring rendering and accessible labelling |
| `.waveform`, `.wave-mini` | Bar generation |
| `Prepeet.query.get/set/all/withParams` | URL state helpers |
| `Prepeet.validate(form)` | Form validation with focus management |
| `Prepeet.announce(msg)` | Polite live-region announcement |
| `Prepeet.band(n)`, `Prepeet.bandLabel(b)` | Score-band mapping |
| `Prepeet.getMode/setMode`, `Prepeet.getRole/setRole/can` | Mode and permission model |
| `Prepeet.init(scope)` | Re-initialises components after dynamic rendering |
